# Day 12 Exercise 1: Add React Router

## Goal

Add React Router to your Support Desk UI.

## Task

1. Install React Router.
2. Wrap your app with `BrowserRouter`.
3. Create basic routes:

```text
/login
/app/dashboard
/app/tickets
```

## Expected result

You can manually type each URL and see a different page component.

## What to submit

A screenshot of each route.
