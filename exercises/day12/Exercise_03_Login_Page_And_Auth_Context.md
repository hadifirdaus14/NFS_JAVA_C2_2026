# Day 12 Exercise 3: Login Page and Auth Context

## Goal

Build a login flow for the Support Desk UI.

## Task

1. Create `AuthContext.jsx`.
2. Store logged-in user and token in state.
3. Create a `login()` function.
4. Create `LoginPage.jsx` with email and password fields.
5. Call your backend login endpoint.

## Expected result

After login, the token is saved and the user can enter the app area.

## Suggested seeded account

Use the account created by your backend seeder.
