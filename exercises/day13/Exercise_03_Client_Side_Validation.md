# Day 13 Exercise 3 - Client-Side Validation

## Scenario

Users should not submit incomplete ticket data.

## Task

Add client-side validation to the ticket form.

## Validation rules

- title is required
- description is required
- category is required
- priority is required
- status is required

Show inline error messages beside or below the relevant field.

## Expected result

The form blocks submission when required fields are empty.
