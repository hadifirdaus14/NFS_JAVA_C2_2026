# Day 13 Exercise 2 - Create Ticket Form Page

## Scenario

You will now build a React page for creating a support ticket.

## Task

Create:

```text
src/pages/TicketFormPage.jsx
src/components/TicketFormWizard.jsx
```

The form should collect:

- title
- description
- category
- priority
- status

## Requirements

- Use controlled inputs.
- Store form values in React state.
- Use labels for every input.
- Add a route for the form page.

Suggested route:

```text
/app/tickets/new
```

## Expected result

The form page opens from the protected area and displays all fields correctly.
