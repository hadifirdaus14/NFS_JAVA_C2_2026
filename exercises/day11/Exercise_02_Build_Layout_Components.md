# D11 Exercise 02 — Build Layout Components

## Goal

Break the UI into reusable components.

## Create these files

```text
src/components/AppHeader.jsx
src/components/Layout.jsx
```

## Requirements

`AppHeader` should show:

```text
Support Desk UI
Day 11 React Fundamentals
```

`Layout` should wrap the page and render children.

Example usage in `App.jsx`:

```jsx
<Layout>
  <p>Ticket dashboard goes here</p>
</Layout>
```

## Submit

Your component tree so far:

```text
App
└── Layout
    └── AppHeader
```
