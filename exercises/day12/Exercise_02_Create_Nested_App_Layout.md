# Day 12 Exercise 2: Create Nested App Layout

## Goal

Create a protected app layout for the Support Desk UI.

## Task

1. Create `AppShell.jsx`.
2. Add navigation using `NavLink`.
3. Add `Outlet` where child pages will render.
4. Create child routes:

```text
/app/dashboard
/app/tickets
/app/reports
```

## Expected result

The navigation stays on screen while the page content changes.
