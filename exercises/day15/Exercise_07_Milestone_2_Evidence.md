# Day 15 Exercise 7 - Milestone 2 Evidence Submission

## Scenario

You need to prove that your Support Desk app works and has basic test coverage.

## Submit evidence

Submit the following in your Github Repository:

1. Screenshot or terminal output of passing Vitest tests.
2. Screenshot or terminal output of passing Playwright smoke test.
3. Screenshot of successful login.
4. Screenshot of protected ticket page.
5. Screenshot of ticket form validation error.
6. Screenshot of successful ticket create or update.

## Review questions (To be completed in Google Classroom)

1. What is a unit test?
2. What is a component test?
3. What is an end-to-end test?
4. Why should protected routes be tested?
5. Why do we mock API responses in component tests?
6. Why does the E2E test need the backend running?
7. Which test gave you the most trouble?
