================================= KEY CONCEPTS =================================

1. Authentication vs Authorisation
Authentication: Who are you? e.g. A user who logins successfully.
Authorisation: What are you allowed to do? The user might not be allowed to create/delete items.

2. Password hashing
NEVER store passwords in plain text
User pwd -> BCrypt hashing -> passwordHash stored in the db
Whenever a user logs in, Spring Security compare the entered pwd against the stored hash

3. JWT idea
JWT JSON Web Token
Server give the client a signed token after login
Client send the token in later requests
Server check the token before allowing any access

4. Client sends a token like this
Authortization: Bearer <token>

401 vs 403
401 Unauthorised. User not logged in, or token is missing/invalid
403 Forbidden. You are logged in, but your role is not allowed to do a certain action

USER and ADMIN
USER = View assets
ADMIN = view and create assets
